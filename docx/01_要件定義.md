# PochiCode 要件定義書

## 1. プロジェクト概要
* **アプリ名:** PochiCode（ポチコード）
* **コンセプト:** 「ポチポチ」とタップする感覚で、ベッドやソファで寝転がりながらでも快適にWebフロントエンドのコーディングができる、iPhone専用の開発支援アプリ。
* **プラットフォーム:** iOS (React Native / Expoを使用して開発)

## 2. ターゲットと利用シーン
* **ターゲットユーザー:** 開発者自身
* **利用シーン:** ベッドやソファで横になっているリラックスタイム。パソコンを開くのが億劫な場面。
* **解決する課題:** スマートフォンのソフトウェアキーボード特有の「プログラミング記号の入力の煩わしさ」を解消。

## 3. システム構成
* **開発環境:** Mac, VS Code
* **使用技術:** React Native, Expo
* **プレビュー環境:** `react-native-webview`

## 4. 機能要件（MVP：初期リリース）
### 4.1. コードエディタ機能
* HTML、CSS、JavaScriptを記述・編集できるテキスト入力エリア。
* スマートフォン画面に最適化されたシンプルなUI。

### 4.2. ライブプレビュー機能
* エディタに入力したコードを、アプリ内のWebViewで即座に実行・表示する。
* エディタ画面とプレビュー画面を1つの画面内に分割表示（またはワンタップで切り替え）。

### 4.3. カスタムスニペットバー（入力補助機能）
* ソフトウェアキーボードの上部に、横スクロール可能な専用ツールバーを配置。
* プログラミングで頻出する記号や定型文をワンタップで入力可能にする。
* **配置する主なボタン:**
  * 記号: `< >`, `{ }`, `[ ]`, `( )`, `" "`, `' '`, `/`, `=`, `;`, `:`
  * 操作: `Tab`（インデント）、`Undo`（取り消し）
  * 定型文: `console.log()`

## 5. 非機能要件
* **操作性:** 片手や仰向けの姿勢でも無理なく指が届く、ストレスフリーなボタン配置。
* **パフォーマンス:** 文字入力からプレビュー反映までのタイムラグを最小限に抑える。

## 6. 将来の拡張要件(02以降)
* **AIコーディングアシスタント:** 音声入力を用いたコードの自動生成・挿入機能。
* **ローカルファイル管理:** 作成したコードの複数保存、読み込み、名前変更などのプロジェクト管理機能。
