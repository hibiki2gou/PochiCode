# PochiCode 詳細設計書

## 1. 画面レイアウト設計（UI構造）
iPhoneの限られた画面サイズを最大限に活かし、タイピングの邪魔にならないよう機能を配置する。

* **ヘッダー領域（最上部固定）:**
  * 「エディタ」と「プレビュー」を切り替えるタブボタンを配置。（入力領域と分離し、誤操作を防ぐ）
* **メイン領域（中央部・画面全体を広く使用）:**
  * **エディタモード時:** HTML/CSS/JSを入力するテキストエリア。
  * **プレビューモード時:** 記述したコードの実行結果を表示するWebView。
* **フッター領域（キーボード上部）:**
  * **カスタムスニペットバー:** キーボードの表示に連動して出現する、横スクロール式の記号入力ボタン群。

## 2. コンポーネント構成（ディレクトリ構造案）
React Native（Expo）の機能を用いて、パーツごとにファイルを分割して開発しやすくする。

```text
PochiCode/
├── App.js                 # アプリの大元（状態管理と画面切り替え）
├── src/
│   ├── components/
│   │   ├── Header.js      # タブ切り替えボタンのコンポーネント
│   │   ├── Editor.js      # テキスト入力エリア
│   │   ├── Preview.js     # WebView表示エリア
│   │   └── SnippetBar.js  # 記号入力用のカスタムツールバー
│   └── styles/
│       └── global.js      # 全体のデザイン（色や余白）の設定
