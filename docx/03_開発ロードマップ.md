## Phase 1: 「書く快適さ」の追求（エディタの強化）

### 入力補完の拡充

| # | タスク | 概要 |
|---|--------|------|
| 1-1 | 改行時のオートインデント | 改行時に直前の行と同じインデントレベルを自動挿入する |
| 1-2 | `{` 後のスマートインデント | `{` の後で改行すると次の行をインデントし、さらに次の行に `}` を自動挿入してカーソルを中に配置する |
| 1-3 | HTML タグ自動クローズ | `<div` + スニペットバーの `>` で `<div></div>` を挿入し、カーソルをタグ内に配置する |

### シンタックスハイライト

| # | タスク | 概要 |
|---|--------|------|
| 1-4 | エディタコンポーネントの選定 | `react-native-code-editor` 等のライブラリを評価し、TextInput を継続するか置き換えるかを決定する |
| 1-5 | HTML タグのハイライト | `<`, `>`, タグ名に色付けする |
| 1-6 | CSS プロパティのハイライト | `color:`, `font-size:` 等のプロパティ名・値に色付けする |
| 1-7 | JS キーワードのハイライト | `const`, `let`, `function` 等に色付けする |
| 1-8 | 文字列・コメントのハイライト | `"..."`, `'...'`, `// ...`, `/* ... */` に色付けする |

### エディタ UI 改善

| # | タスク | 概要 |
|---|--------|------|
| 1-9 | 行番号の表示 | エディタ左端に行番号を表示する |
| 1-10 | カーソル行ハイライト | カーソルがある行の背景を薄く強調する |
| 1-11 | `SafeAreaView` の deprecation 対応 | `react-native-safe-area-context` の `SafeAreaView` に移行する |

## Phase 2: 「プロジェクト管理」の導入（複数ファイル対応）

### 永続化

| # | タスク | 概要 |
|---|--------|------|
| 2-1 | 単一ファイルの自動保存 | `AsyncStorage` を導入し、入力のたびにコードを自動保存（debounce: 500ms）。アプリ起動時に前回の内容を復元する |
| 2-2 | `expo-file-system` の導入 | 複数ファイル対応に向け、ローカルファイルシステムへの読み書き基盤を構築する |

### ファイル管理

| # | タスク | 概要 |
|---|--------|------|
| 2-3 | ファイルのデータ構造設計 | ファイル・フォルダのツリー構造の型定義（`FileNode` 等）を設計する |
| 2-4 | 新規ファイル作成 | ファイル名を入力して新しいファイルを作成する UI と処理を実装する |
| 2-5 | ファイルの削除・リネーム | 長押しメニューから削除・リネームできる機能を実装する |
| 2-6 | ファイルツリー UI（ドロワー） | 画面左端からスワイプで出現するファイル一覧パネルを実装する |
| 2-7 | エディタ内タブ切り替え | 開いているファイルをタブで切り替えられる UI を実装する |

### 統合プレビュー

| # | タスク | 概要 |
|---|--------|------|
| 2-8 | HTML / CSS / JS の統合プレビュー | 別ファイルに書かれた CSS を `<style>` タグ、JS を `<script>` タグとして HTML に埋め込んでから WebView に渡す処理を実装する |

## Phase 3: 「AIとの共創」と「PCとの連携」（スマート化）

### AI コーディングアシスタント

| # | タスク | 概要 |
|---|--------|------|
| 3-1 | AI API の選定とキー管理 | Claude / GPT / Gemini を評価して選定。`expo-secure-store` で API キーを安全に保管する |
| 3-2 | AI チャット UI | 画面下部からスワイプで出現するチャットパネルを実装する |
| 3-3 | 選択テキストを AI に送る機能 | エディタで選択した範囲のコードをコンテキストとして AI に送信する |
| 3-4 | AI レスポンスのエディタへの挿入 | AI が生成したコードを現在のカーソル位置、または選択範囲と置換して挿入する |
| 3-5 | エラーの AI 解析連携 | Phase 4 のエラー検知と連携し、エラー内容をワンタップで AI に質問できるようにする |

### Mac / VS Code 連携

| # | タスク | 概要 |
|---|--------|------|
| 3-6 | GitHub OAuth 認証 | アプリ内から GitHub にログインする OAuth フローを実装する |
| 3-7 | リポジトリ一覧・選択 UI | 認証後にリポジトリ一覧を取得して選択できる UI を実装する |
| 3-8 | ファイルの push 機能 | 編集したファイルを GitHub リポジトリに push する機能を実装する |
| 3-9 | ファイルの pull・同期機能 | リポジトリの最新状態を pull してエディタに反映する機能を実装する |
